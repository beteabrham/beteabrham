# Bete Abrham — Portfolio Website

> **Digital Marketing Strategist, UI/UX Designer & Frontend Developer** based in Addis Ababa, Ethiopia.

A modern, fast, and responsive personal portfolio showcasing digital marketing campaigns, UI design systems, and frontend web applications.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography**: [Geist](https://vercel.com/font)
- **Icons**: [Lucide React](https://lucide.dev/) & Custom Brand SVGs
- **Language**: [TypeScript](https://www.typescriptlang.org/)

---

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/xcpurp/beteabrham.git
   cd beteabrham
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3001](http://localhost:3001) in your browser to view the site.

---

## 📦 Build & Production

To create an optimized production build:

```bash
npm run build
```

To run the production server locally:

```bash
npm run start
```
*(Runs on port 3001: [http://localhost:3001](http://localhost:3001))*

## 📁 Project Structure

```text

│   ├── globals.css        # Global CSS & Tailwind v4 theme definitions
│   ├── layout.tsx         # Root layout with SEO metadata & dark mode
│   └── page.tsx           # Home page aggregating all sections
├── components/
│   ├── About.tsx          # Info, narrative, and key career metrics
│   ├── Contact.tsx        # Direct contact, social links, and availability
│   ├── Experience.tsx     # Career journey, education, and certifications
│   ├── Footer.tsx         # Site footer and back-to-top navigation
│   ├── Hero.tsx           # Headline, portrait photo, and call-to-actions
│   ├── Navbar.tsx         # Sticky navigation with theme toggle (Dark/Light)
│   ├── Projects.tsx       # Featured project showcases & explorations
│   ├── Skills.tsx         # Core capabilities and service offerings
│   └── TechMarquee.tsx    # Infinite scrolling engineering ticker
├── lib/
│   ├── data.ts            # Portfolio data, links, bio, and content
│   └── utils.ts           # Class merging helper (clsx & tailwind-merge)
└── public/
    └── bete-smiling.png   # Profile portrait
```
